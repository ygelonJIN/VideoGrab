视频下载器 设置

嗅探到的真实 Referer / UA / Cookie 会自动带给 aria2 和 ffmpeg，不用再手动 Copy as cURL。

aria2（MP4 多线程下载）

aria2c --enable-rpc --rpc-listen-all=false --rpc-allow-origin-all --continue=true

本地助手（M3U8 → ffmpeg 合并）

cd 视频下载器/helper && ./start.sh

网络代理

嗅探

用法

  1. 打开播放页，点一次播放。
  2. 点工具栏图标（或 Alt+Shift+V），列表里会冒出媒体。
  3. MP4 / WebM 这类完整文件点 ⚡ 交给 aria2，多线程比浏览器快很多。
  4. M3U8 / DASH 点 解析，看清清晰度和时长，再「复制 ffmpeg 命令」或「交给助手」。
  5. 要批量：勾选多条 → aria2 下载，或者 导出 txt 后用 aria2c -i 文件.txt。
